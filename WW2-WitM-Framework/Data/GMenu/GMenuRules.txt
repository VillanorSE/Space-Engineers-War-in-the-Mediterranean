# WitM G menu rules, read by Scripts/WW2-WitM/GMenu/GMenuSession.cs when a world loads (on every client).
# Preview: se-mod-production tools/gmenu/gmenu_preview.py reads this same file.
#
# tab <key> <category Name>          a WitM tab, declared in Data/GMenu/BlockCategories.sbc (the Name sets the order)
# keep <category Name>               a category that stays as it is (ship, tool and animation categories always stay)
# define <NAME> <a,b,c>              a list, used as @NAME in the mods or types field
# rule <tab> <mods> <types> <subtypes>
#     Every cube block goes in the tab of the FIRST rule it matches. mods: Workshop IDs, "vanilla" or a local mod
#     folder name; types: TypeId without MyObjectBuilder_; subtypes: patterns where * is the only wildcard
#     (not case sensitive). Each field is a comma list or *. Subtypes is the rest of the line, so it may hold spaces.
# rulename <tab> <mods> <types> <display names>   like rule, but matches the block's (English) display name
# incat <tab> <category Name>        blocks the mods themselves listed in that category (read before the cleanup)
# move <category Name> <category Name>  add the first category's items to the second, then hide the first
#
# Every other category is hidden and emptied.
